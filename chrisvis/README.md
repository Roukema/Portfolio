# Chrisvis

Portfoliowebsite voor Chrisvis (Christiaan Roukema) — handgemaakt houtwerk: meubels, kistjes, snijplanken en klussen.

Statische site, geen build-stap nodig: open `index.html` in de browser, of serveer de map met een simpele static server, bijvoorbeeld:

```
npx serve .
```

## Structuur

- `index.html` — de pagina
- `css/style.css` — styling
- `js/main.js` — menu + lightbox voor de projectfoto's
- `assets/img/` — logo's en projectfoto's
- `assets/favicon.svg`

## Nog te doen

- Logo: `assets/img/logo-chrisvis.svg` en `logo-roukema.svg` zijn een nagemaakte versie van het originele logo (het originele bestand kwam niet als los bestand binnen). Vervang deze door de echte logo-bestanden zodra beschikbaar.
- Contact: het e-mailadres in de contactsectie (`info@chrisvis.nl`) is een placeholder — vervang door het echte contactadres.
